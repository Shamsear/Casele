# CASELÉ UX Audit — Comparing with MAX, Noon, Amazon

## 📊 Executive Summary

CASELÉ has a beautiful design but lacks the **conversion-focused features** that drive sales on sites like MAX and Noon. The biggest gaps are in **promotional visibility**, **urgency creation**, and **checkout simplicity**.

---

## 🚨 CRITICAL MISSING FEATURES

### 1. Announcement Bar (Sticky Top)
```
What MAX does:
┌─────────────────────────────────────────────┐
│ 🎉 20% OFF First Order | Use Code: WELCOME │
└─────────────────────────────────────────────┘
```
**Why it works:** First thing users see. Creates immediate value proposition.

**What we need:**
- Sticky bar at top
- Current promotion text
- Dismissible but returns on refresh
- Rotates between offers

---

### 2. Hero Banner Carousel
```
What MAX does:
┌─────────────────────────────────────────────┐
│ [Image 1] [Image 2] [Image 3]              │
│                                              │
│    SUMMER SALE                               │
│    Up to 60% OFF                             │
│    [Shop Now]                                │
└─────────────────────────────────────────────┘
```
**Why it works:** Shows multiple promotions, keeps site fresh.

**What we need:**
- 3-4 slide carousel
- Current sale/promotion
- New arrivals
- Seasonal collection

---

### 3. Flash Sale Section with Countdown
```
What Noon does:
┌─────────────────────────────────────────────┐
│ ⚡ FLASH SALE                               │
│ Ends in: 02:34:56                           │
│                                              │
│ [Product] [Product] [Product] [Product]     │
│  QR 79      QR 59      QR 89      QR 69     │
│  ~~QR 99~~  ~~QR 79~~  ~~QR 109~~ ~~QR 89~~ │
└─────────────────────────────────────────────┘
```
**Why it works:** Creates urgency (FOMO). Users buy NOW or miss out.

**What we need:**
- Countdown timer (hours:minutes:seconds)
- Products with original vs sale price
- Progress bar showing "75% sold"
- Auto-rotates between flash sales

---

### 4. Free Delivery Threshold
```
What Amazon/Noon does:
┌─────────────────────────────────────────────┐
│ 🚚 Add QR 21 more for FREE delivery!       │
│ [████████████░░░░] 79% there               │
└─────────────────────────────────────────────┘
```
**Why it works:** Increases average order value. Users add more to get free delivery.

**What we need:**
- Progress bar in cart
- "Add QR X more for free delivery"
- Show threshold prominently

---

### 5. Limited Stock / Low Inventory
```
What Noon does:
┌─────────────────────────────────────────────┐
│ ⚠️ Only 3 left in stock!                    │
│ 🔥 15 people are viewing this               │
└─────────────────────────────────────────────┘
```
**Why it works:** Creates urgency. Users buy before it's gone.

## 🟠 MAJOR IMPROVEMENTS NEEDED

### 6. Sticky Add to Cart (Mobile)
```
What MAX does on mobile:
┌─────────────────────────────────────────────┐
│ [Image] Product Name          QR 79         │
│ [Add to Cart Button - Full Width]           │
└─────────────────────────────────────────────┘
```
**Why it works:** Always visible, one-tap purchase.

---

### 7. Recently Viewed Products
```
What Amazon does:
┌─────────────────────────────────────────────┐
│ Your Recently Viewed Items                  │
│ [Product] [Product] [Product] [Product]     │
└─────────────────────────────────────────────┘
```

**Why it works:** Users come back to items they liked. Reduces friction.

```tsx
  🎉 20% OFF First Order — Use Code: WELCOME20
```

### 2. Free Delivery Banner in Cart
```tsx
// Add to cart-drawer.tsx
{subtotal() < 100 && (
  <div className="bg-emerald-500/10 text-emerald-400 text-sm p-3 rounded-lg">
    🚚 Add QR {100 - subtotal()} more for FREE delivery!
  </div>
)}
```

### 3. Limited Stock Badge
```tsx
// Add to product card
{product.stock < 5 && (
  <span className="text-red-400 text-xs">⚠️ Only {product.stock} left!</span>
)}
```
